# 2. EKF2 — Extended Kalman Filter (24-state)

## 2.1. Role

EKF2 is the "source of truth" for the aircraft state. It **fuses** all asynchronous sensors (IMU 1 kHz, GPS 5–10 Hz, baro 50 Hz, mag 100 Hz, vision 30 Hz, ...) into a consistent estimator: attitude, velocity, position, gyro/accel bias, magnetic field, wind, terrain height.

PX4 runs EKF2 at a **delayed time horizon** (≈ 100 ms delay) so that any late-arriving sensor can still be placed in the correct temporal order; an **output predictor** then propagates forward to real time using the latest IMU data.

## 2.5. Prediction Step

### Nominal state update

Using IMU (`vehicle_imu`) integration:

$$
\hat{\boldsymbol{q}}_{k+1} = \hat{\boldsymbol{q}}_k\otimes \exp_{\boldsymbol{q}}\!\left(\tfrac{1}{2}(\boldsymbol{\omega}_m-\hat{\boldsymbol{b}}_g)\Delta t\right)
$$

$$
\boldsymbol{a}_W = \boldsymbol{R}(\hat{\boldsymbol{q}})(\boldsymbol{a}_m-\hat{\boldsymbol{b}}_a) + \boldsymbol{g}_W,\quad \boldsymbol{g}_W=(0,0,g)^\top
$$

$$
\hat{\boldsymbol{v}}_{k+1} = \hat{\boldsymbol{v}}_k + \boldsymbol{a}_W\Delta t,\qquad
\hat{\boldsymbol{p}}_{k+1} = \hat{\boldsymbol{p}}_k + \hat{\boldsymbol{v}}_k\Delta t + \tfrac{1}{2}\boldsymbol{a}_W\Delta t^2
$$

**Variable explanation**:
- $\hat{\boldsymbol{q}}_k$: quaternion estimate at step $k$ (nominal state).
- $\boldsymbol{\omega}_m$: raw gyro measurement (offline-calibrated as in §1.4.1).
- $\hat{\boldsymbol{b}}_g$: current gyro bias estimate (EKF state).
- $\boldsymbol{\omega}_m-\hat{\boldsymbol{b}}_g$: estimated true angular rate → integrated into a quaternion increment.
- $\boldsymbol{a}_m$: raw accel, $\hat{\boldsymbol{b}}_a$: estimated accel bias.
- $\boldsymbol{R}(\hat{\boldsymbol{q}})=\boldsymbol{R}_{WB}$: rotates specific force from $\{B\}$ to $\{W\}$.
- $+\boldsymbol{g}_W$: adds gravity to obtain the true acceleration in $\{W\}$ (because the accelerometer measures specific force = acceleration minus g projected into $\{B\}$).
- $\Delta t$: IMU period (≈ 1–2 ms).
- $\exp_{\boldsymbol{q}}(\boldsymbol{\theta}/2)=(\cos\lVert\boldsymbol{\theta}\rVert/2,\ \mathrm{sinc}(\lVert\boldsymbol{\theta}\rVert/2)\boldsymbol{\theta}/2)$: exponential map.

### Covariance update (error-state)

$$
\boldsymbol{P}_{k+1} = \boldsymbol{F}\boldsymbol{P}_k\boldsymbol{F}^\top + \boldsymbol{G}\boldsymbol{Q}\boldsymbol{G}^\top
$$

**Variable explanation**:
- $\boldsymbol{P}_k\in\mathbb{R}^{24\times24}$: error-state covariance at step $k$.
- $\boldsymbol{F}=\partial f/\partial\delta\boldsymbol{x}$: process model Jacobian (24×24), auto-generated from SymPy → `predict_covariance.h`. Propagates errors from step $k$ to $k+1$.
- $\boldsymbol{G}$: process noise Jacobian (24×$n_w$), maps the noise vector $\boldsymbol{w}\sim\mathcal{N}(0,\boldsymbol{Q})$ into the state space.
- $\boldsymbol{Q}$ is block-diagonal containing: IMU noise (`EKF2_GYR_NOISE`, `EKF2_ACC_NOISE`) + bias random walk (`EKF2_GYR_B_NOISE`, `EKF2_ACC_B_NOISE`).

Error-state for rotation:

$$
\delta\boldsymbol{\theta}_{k+1} \approx (I - [(\boldsymbol{\omega}_m-\hat{\boldsymbol{b}}_g)]_\times\Delta t)\,\delta\boldsymbol{\theta}_k - \delta\boldsymbol{b}_g\Delta t - \boldsymbol{n}_g\Delta t.
$$

- $[(\boldsymbol{\omega}_m-\hat{\boldsymbol{b}}_g)]_\times$: 3×3 skew-symmetric matrix of the angular rate vector → represents the cross product as a matrix multiplication.
- $\delta\boldsymbol{b}_g$: error-state of the gyro bias.
- $\boldsymbol{n}_g$: gyro noise (assumed white Gaussian).
- This corresponds to the $\partial f/\partial\delta\boldsymbol{\theta}$ + $\partial f/\partial\delta\boldsymbol{b}_g$ + $\partial f/\partial\boldsymbol{n}_g$ blocks in $\boldsymbol{F},\boldsymbol{G}$ for the quaternion component.

## 2.6. Measurement Update Step

For each sensor with residual:

$$
\boldsymbol{z}=\boldsymbol{y}-h(\hat{\boldsymbol{x}}),\quad
\boldsymbol{H}=\partial h/\partial\delta\boldsymbol{x}
$$

**Variable explanation**:
- $\boldsymbol{y}$: actual measurement vector from the sensor (e.g. $\boldsymbol{p}_{GPS}$).
- $h(\hat{\boldsymbol{x}})$: predicted measurement based on current state (see table below).
- $\boldsymbol{z}$: **innovation** = observed − predicted difference.
- $\boldsymbol{H}$: observation Jacobian with respect to the error-state (auto-generated `compute_*_h.h`).

Innovation covariance, Kalman gain:

$$
\boldsymbol{S} = \boldsymbol{H}\boldsymbol{P}\boldsymbol{H}^\top + \boldsymbol{R},\qquad
\boldsymbol{K} = \boldsymbol{P}\boldsymbol{H}^\top\boldsymbol{S}^{-1}
$$

- $\boldsymbol{R}$: measurement noise (each sensor has its own, e.g. `EKF2_GPS_P_NOISE`).
- $\boldsymbol{S}$: predicted innovation covariance (if the state and noise are correctly distributed, $\boldsymbol{z}\sim\mathcal{N}(0,\boldsymbol{S})$).
- $\boldsymbol{K}$: blending coefficient — how much of the innovation is "trusted" to correct the state.

**Innovation gating (chi-square test)**:

$$
\boldsymbol{z}^\top\boldsymbol{S}^{-1}\boldsymbol{z} < \gamma^2
$$

- The left side = squared **Mahalanobis distance** of the innovation.
- $\gamma$ = `EKF2_*_GATE` (default 5 sigma). The right side $\gamma^2$ = chi-square threshold.
- If the test fails → reject sample, no update (outlier rejection).

**Update**:

$$
\delta\boldsymbol{x} = \boldsymbol{K}\boldsymbol{z}
$$

$$
\hat{\boldsymbol{q}} \leftarrow \hat{\boldsymbol{q}}\otimes\exp_{\boldsymbol{q}}(\delta\boldsymbol{\theta}/2),\quad
\hat{\boldsymbol{v}}\leftarrow\hat{\boldsymbol{v}}+\delta\boldsymbol{v},\ \dots
$$

$$
\boldsymbol{P} \leftarrow (\boldsymbol{I}-\boldsymbol{K}\boldsymbol{H})\boldsymbol{P}\quad(\text{Joseph form used in code to maintain symm/PSD})
$$

- $\delta\boldsymbol{x}=(\delta\boldsymbol{\theta},\delta\boldsymbol{v},\delta\boldsymbol{p},\dots)$: error-state correction (24-dim).
- The quaternion component is applied via $\boxplus$ (multiplicative); other states are corrected additively.
- **Joseph form**: $(\boldsymbol{I}-\boldsymbol{K}\boldsymbol{H})\boldsymbol{P}(\boldsymbol{I}-\boldsymbol{K}\boldsymbol{H})^\top + \boldsymbol{K}\boldsymbol{R}\boldsymbol{K}^\top$ — numerically robust (maintains symmetric + PSD even under round-off).

### Representative observation functions

| Sensor | $h(\boldsymbol{x})$ |
|---|---|
| GPS pos | $\boldsymbol{p}_W$ |
| GPS vel | $\boldsymbol{v}_W$ |
| Baro height | $-p_z + h_{ref}$ |
| Mag (3-axis) | $\boldsymbol{R}^\top\boldsymbol{m}_I + \boldsymbol{m}_B$ |
| Optical flow | $-\boldsymbol{R}^\top\boldsymbol{v}_W/h_t + \boldsymbol{\omega}-\boldsymbol{b}_g$ |
| Range finder | $h_t - p_z$ |
| Vision pose | $\boldsymbol{p}_W$ and/or $\boldsymbol{q}$ |

## 2.7. Output predictor

The EKF runs at the "delayed horizon" → prediction to the present time is needed using the latest IMU:

$$
\boldsymbol{q}_{out,k} = \boldsymbol{q}_{out,k-1}\otimes\exp_{\boldsymbol{q}}(\tfrac{1}{2}(\boldsymbol{\omega}_m-\hat{\boldsymbol{b}}_g)\Delta t)
$$

+ velocity/position integration. A "tracking error correction" loop gradually pulls $\boldsymbol{q}_{out}$ back toward $\hat{\boldsymbol{q}}$ each time the delayed-EKF produces a new sample (see `output_predictor/`).

## 2.8. EKF Selector (multi-IMU)

When an airframe has 2–3 IMUs, each IMU runs a separate EKF instance. `EKF2Selector.cpp` selects the EKF with the lowest `combined_test_ratio` (best innovation quality) as the output. When one IMU fails (e.g. sudden drift), the selector switches to another EKF — this is **fault-tolerant estimation**.

## 2.9. Reset events

EKF2 may "reset" when: GPS becomes valid for the first time, a large glitch occurs, or a vision setpoint changes abruptly. On reset it publishes `delta_*_reset` so that downstream controllers (pos/att) can **compensate** their setpoints instead of experiencing a sudden jump. See `MulticopterPositionControl::adjustSetpointForEKFResets`.
